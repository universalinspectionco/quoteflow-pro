# QuoteFlow Pro Remake

A modern, premium quotation & price book management system rebuilt with:
- **React 19 + TypeScript** + **Vite 8**
- **Tailwind CSS v4** with glassmorphism & customizable theme engine
- **Electron 33** for desktop packaging
- **Google Gemini AI** (AI Quote Studio)
- **PDF Export** matching official UIC `Quote Format .pdf` template
- **Excel Export** matching official UIC `Quote Format.xlsx` template

## Getting Started

```bash
npm install
npm run dev          # Dev server at http://localhost:1420
npm run build        # Production build
npm run package:windows  # Windows installer + portable
```

## Design Philosophy

- **Snapchat / Facebook / iOS inspired**: Glassmorphism, fluid transitions, rounded cards, interactive badges
- **Customizable theme engine**: Dynamic palette picker, live accent colors, dark/light/system themes
- **Premium experience**: Live document preview, command palette, smart export matching
- **Feature parity**: All V1/V2 features preserved, rebuilt with modern UI patterns
